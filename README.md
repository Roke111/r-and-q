# 我们的纪念册 · 一周年

一个向上滑动翻页的纪念册网页。纯 **HTML + CSS + 原生 JavaScript** 实现，
零框架、零 npm 依赖、**零外部 CDN**，可完全离线运行，手机端优先。

---

## 快速开始

```bash
# 方式一：直接双击打开
open index.html

# 方式二：本地服务器（推荐，手机同局域网可访问）
python3 -m http.server 8899
# 访问 http://127.0.0.1:8899
```

手机浏览器访问时用局域网 IP，例如 `http://192.168.1.10:8899`。

> 背景音乐受浏览器自动播放策略限制，首次需要点一下页面或右上角的音符按钮才会响。

## 要改内容？只改 `js/data.local.js`

内容分成两层，你**只需要碰其中一个文件**：

```
js/data.js        示例层 ── 通用示例内容，让页面在没填内容时也能直接跑起来
      ↓ 被覆盖
js/data.local.js  真实层 ── ★ 你自己的名字、日期、故事、照片清单 ★
      ↓
   js/main.js     合并两层 → 渲染到 index.html 的 11 个 <section>
```

**规则只有一条：填了哪一项，哪一项就以你的为准；留空的自动沿用示例内容。**

- `""`（空字符串）和 `[]`（空数组）都算「没填」，会被忽略；
- `null` = **显式清空**：连示例内容也不显示（示例的说明性文字会漏到页面上时用它）；
- 所以你可以**只填一半**，页面照样正常跑，不会空白也不会报错；
- 数组（时间线 / 地点 / 数据 / 照片 / 词云 / 小目标 / 心动瞬间 / 愿望）是**整体替换**：
  只要你写了内容，就完全用你那份，不再和示例混排；
- **数组里的空条目不会渲染**：填上内容它才出现，所以能一条一条慢慢补，页面不会被空行撑开
  （判空只看文本字段——`x`/`y`/`weight`/`decimals`/`span`/`pos`/`milestone` 这类属性不算「有内容」）；
- `data.local.js` 已随站点一起发布 —— 线上页面就是靠它渲染的。

> **⚠️ 隐私提示：本仓库是公开仓库，`https://roke111.github.io/r-and-q/` 任何人都能打开。**
> `js/data.local.js` 里有真实姓名、日期和故事，`assets/photos/` 是真人照片，
> `assets/bgm.m4a` 是第三方音乐 —— 这些**都已经公开**，并且会永久留在 git 历史里
> （之后删掉文件也没用，历史仍可翻出）。
> 页面带 `<meta name="robots" content="noindex">`，搜索引擎不会收录，但**不等于**私密。
> 想让它彻底下线，见文末「下线与撤回」。

`.gitignore` 里仍然排除的只有 `assets/photos/_originals/`（17MB 原图备份）
和两个工作文件 `待填写信息清单.md` / `预览-11屏总览.png`。

逐字段该填什么、当前值是什么，见 [`待填写信息清单.md`](./待填写信息清单.md)。

## 字体：系统黑体，不加载任何外部字体

```css
/* css/style.css 顶部 :root */
--font:-apple-system,BlinkMacSystemFont,"PingFang SC","Heiti SC","Hiragino Sans GB",
       "Microsoft YaHei","Noto Sans CJK SC","Source Han Sans SC",
       "WenQuanYi Micro Hei",sans-serif;
```

- Apple 设备命中 **苹方 PingFang SC**（`-apple-system` 对中文即苹方），
  Windows 命中 **微软雅黑**，Android 命中 **思源黑体**，Linux 有文泉驿兜底。
- 好处：**离线能开、国内和微信里不会掉字、不向第三方发请求**（页面零外部请求）。
- 想优先用 macOS 上字面的「黑体-简」，把 `"Heiti SC"` 挪到 `"PingFang SC"` 前面即可。
- 改全文正文字重看 `body{font-weight:300}`；黑体 300 在 Apple 上是 Light，偏细，
  嫌细就改成 `400`。

## 常见修改速查

| 想改什么 | 改哪里 | 怎么改 |
|---|---|---|
| 两个人名字 | `data.local.js` → `cover.names` | 直接改字符串 |
| 纪念日 / 天数 | `data.local.js` → `cover.date` | 手写文案，**天数不会自动算** |
| 封面大标题 | `data.local.js` → `cover.title` | **支持简单 HTML**，如 `那些<br>我们经历的` 换行 |
| 时间线 | `data.local.js` → `timeline[]` | 照注释里的结构加；`milestone: true` 的点会高亮 |
| 地图上的城市 | `data.local.js` → `places[]` | `x` / `y` 是 0~100 的百分比坐标 |
| 数据数字 | `data.local.js` → `stats[]` | `decimals: 0` 取整＋千分位；`>0` 保留小数 |
| 照片 | `assets/photos/` + `data.local.js` → `photos[]` | 见下节 |
| 照片裁切位置 | `data.local.js` → `photos[].pos` | 如 `"50% 30%"`，数字越小越靠上，用于避开尴尬裁切 |
| 词云 | `data.local.js` → `words[]` | `weight` 1~5，越大字越大、越不透明 |
| 心情曲线 | `data.local.js` → `mood` | `labels` 与 `values` 建议等长；`values` 0~100，≥90 的点高亮 |
| 小目标 / 心动瞬间 / 愿望 | `data.local.js` → `goals[]` / `moments[]` / `wishes[]` | 数组增删自由 |
| 结尾信 | `data.local.js` → `end.letter[]` | 每个数组项 = 一个自然段 |
| 背景音乐 | `assets/bgm.m4a`（或 `bgm.mp3`） | **文件名固定**，不用填路径；`music.title/artist` 只控制右上角曲名 |
| 屏幕顺序 | `index.html` 的 `<section class="card">` | 移动整段 `<section>`，并同步改 `<span class="idx">02</span>` 编号 |
| 字体 | `css/style.css` → `:root` 的 `--font` | 换字体栈即可全站生效 |
| 配色 | `css/style.css` 顶部 `:root` | 改 `--bg` / `--rose` / `--gold` / `--violet` 等变量即可全站生效 |
| 分享封面 | `assets/og-cover.jpg` | 自己裁一张 1200×630 覆盖即可 |

## 照片怎么放

照片放在 `assets/photos/`，文件名与 `data.local.js` 里 `photos[].src` 一致时自动显示。

当前六张的槽位是**按每张图的长宽方向配的**——竖图给竖槽、横图给横槽，
这样裁掉的边最少，网格里也不会留下空格：

| 文件 | 说明 | 布局 | 原图方向 |
|---|---|---|---|
| `01.jpg` | 第一次旅行 | `span:"wide"` 横跨两格 | 竖 3:4 |
| `02.jpg` | 技术的巅峰 | `span:"tall"` 竖向拉长 | 竖长图 |
| `03.jpg` | 跟我回家 | 正方形 | 横 4:3 |
| `04.jpg` | 陪你过生日 | 正方形 | 竖 3:4 |
| `05.jpg` | 猫猫到家 | 正方形 | 竖 3:4 |
| `06.jpg` | 一起看演唱会 | `span:"wide"` 横跨两格 | 横 4:3 |

- **照片缺失不会报错**：会显示一个占位块，上面写着该放的文件名，方便对照。
- 图片按 `object-fit: cover` 裁切，比例不符不变形，只裁边缘；裁得不合适就调该图的 `pos`。
- 换照片时若方向变了（横↔竖），把 `span` 一起改掉，否则会裁得很狠。
- 建议单张压到 300KB 以内，长边 1600px 左右。

## 已知事项

- **两屏比一屏略高**（实测 iPhone 14 Pro Max 430×932）：
  「相识时间线」高 1392px（超 460px，13 条）、「照片回忆墙」高 1066px（超 134px）。
  因为 `.deck` 用的是 `scroll-snap-type: y mandatory`，本来就担心超高卡片会被吸附回去
  导致末尾够不着——实测**不会**，卡片高于视口时可以停在卡片内部，末尾内容够得着，
  只是这两屏需要多滑一段。想让每屏刚好一屏，见下面「可选优化」。
- **词云里长句会折行**：`1月30日，通话时长2:23:55` 在 430 宽屏占 363px（一行），
  但在 390 / 360 宽的机器上会折成两行。想避免就把这几条长句的 `weight` 降到 1~2，
  字号会降到 15~20px，一行放得下。
- 封面标题「那些我们经历的」宽 370px，右侧圆点导航空余 **13px**（390 宽时 10px）。
  不重叠，但比较紧。想更宽松就让 `cover.title` 用 `<br>` 分两行，或调小 `.title` 的 `clamp()` 上限。
- `index.html` 带 `<meta name="robots" content="noindex">`，语义是「不被搜索引擎收录」。
  **线上保留着** —— 它挡的是搜索引擎，不挡直接访问链接的人。
- `assets/og-cover.jpg` 已生成（1200×630，取自 `03.jpg`），供分享时展示。**已随站点发布。**
- 愿望清单的勾选状态只存在内存里，刷新页面会清空。要持久化就在 `main.js` 的 `toggle()` 里加一层 `localStorage`。
- 合并逻辑在 `main.js` 的「1.5 内容分层合并」段落，约 30 行；空位过滤是 `isEmptyValue()` + `dropEmptySlots()`。

### 下线与撤回

想停止公开访问有两个层次，效果和代价不同：

1. **让它访问不了（推荐，可逆）**
   仓库 Settings → Pages → Source 改成 `None`，或直接把仓库转为 **Private**。
   ⚠️ 注意：Free 套餐下私有仓库**不能**开 Pages，所以转私有会顺带停掉站点；
   而 Pro 套餐下私有仓库的站点**依然是公开的**（官方明确说明），私有只保护源码。
2. **抹掉内容（不可逆，必须重写历史）**
   已经推送的内容会留在 git 历史里，只删文件是没用的。要彻底清除需用
   `git filter-repo` 重写全部历史后强推，或直接**删除整个仓库**重建。
   `assets/photos/_originals/` 里的 17MB 原图**从未推送过**，不受影响。

### 可选优化（没做，想要说一声）

1. **时间线分两屏**：把 13 条拆成 02（前期）+ 02b（后来），每屏就都能一屏放下，
   代价是屏数从 11 变 12，`<span class="idx">` 编号要顺延。
2. **照片墙收成一屏**：六张全用正方形（去掉两个 `wide`），网格 3 行，高度约 810px，正好一屏。
3. **时间线紧凑模式**：把每条的下间距从 22px 收到 14px，能省约 104px，仍放不下 13 条。
